# Data Science Projects

Four projects covering machine learning, SQL analytics, a Power BI dashboard and an AWS pipeline.
Each folder has its own README with setup and results.

| Project | Area | Stack |
|---|---|---|
| [telco_churn_prediction](telco_churn_prediction) | Machine learning | Python, scikit-learn |
| [retail_sql_analytics](retail_sql_analytics) | SQL | SQLite, CTEs, window functions |
| [hr_attrition_dashboard](hr_attrition_dashboard) | Data analysis, Power BI | pandas, DAX, Chart.js |
| [weather_etl_aws](weather_etl_aws) | Cloud | AWS SAM, Step Functions, Lambda, S3, Athena |

Notes
- All datasets are synthetic, generated by scripts in each folder so results are reproducible.
- The retail database is not committed. Run `python3 build_db.py` in `retail_sql_analytics` to create it.
- The AWS project is tested locally (`python3 local_run.py`) and has not been deployed.
- The HR dashboard is an HTML version of the report page. The DAX model is documented in `dax_measures.md`.
